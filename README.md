# Solaris  
Solaris is an open source interplanetary space flight simulator.  

## Running Solaris  
1. Download the `.zip` archive.  
2. Unzip the archive to a (preferably) empty directory.  
3. Run main.py.  
4. If for some reason it returns an error regarding the `"ship"` object not existing, open the installed directory and run it from there.  

## Controlling the ship  
| Key | Function |  
|-----|----------|  
|  ⬆️ | Thrust forwards |  
|  ⬇️ | Thrust backwards |  
|  ⬅️ | Rotate counterclockwise |  
|  ➡️ | Rotate clockwise |  
| Space | Space breaks |  
|  C  |  Print current coordinate location* |  

(* Only prints when run in a terminal)
